About this mock API

A tiny Node server that generates 400 vehicles, serves them over REST, and streams position updates over Server-Sent Events. No databases, no third-party services.

Endpoints

MethodPathDescription
GET/vehiclesAll 400 vehicles. Supports ?_page=&_limit=, ?status=active, ?q=Smith.
GET/vehicles/:idA single vehicle.
GET/positionsSSE stream — a position event every 5 s with updated lat/lng.
